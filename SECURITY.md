# Security Policy

## Intended Use

Impacket is not intended to be used in production environments.

If you believe you have identified an issue that may affect the security of Impacket users, or if you believe Impacket is being abused or misused, please follow the reporting guidance below.

## Reporting a Security Issue

If you believe you have discovered a security vulnerability in Impacket, or if you believe Impacket is being abused or misused, please report it through Fortra’s vulnerability reporting form:

https://www.fortra.com/security/report

In the **Product** field, enter: **Impacket**.

Please do not report security vulnerabilities, abuse, or misuse through public GitHub issues, discussions, or pull requests.

When reporting a security issue, please include as much detail as possible, including:

* The affected Impacket version or commit, if applicable
* The operating system and environment where the issue was found, if applicable
* A description of the issue
* Steps to reproduce the issue, proof-of-concept details, screenshots, or other supporting evidence, if available
* The potential impact
* Any suggested remediation, if known
* Contact information so Fortra can follow up

Fortra will review submitted reports and follow up as appropriate.
